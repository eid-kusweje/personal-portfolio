# Personal Portfolio

A static, responsive portfolio for Eid Kusweje, built with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — Home page
- `about.html` — Background, education, skills, and contact form
- `projects.html` — Selected project concepts
- `animations.html` — Motion and interaction examples

The shared stylesheet and JavaScript are in `css/` and `js/`. Local image assets are in `images/`.

## Run locally

Open `index.html` in a browser, or serve the `PersonalPortfolio` folder with any static file server. Use the navigation links and calls to action to move between the four pages.

The contact form opens the visitor's default email app. Update the recipient address in `js/script.js` before publishing.
